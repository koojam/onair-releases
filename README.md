# On Air releases

Downloads and the update feed for **On Air**, a floating microphone that types what you say into any app on your Mac.

- **Download:** grab the latest `.dmg` from [Releases](https://github.com/koojam/onair-releases/releases/latest), open it, and drag On Air into Applications.
- **Updates:** On Air checks `appcast.xml` here and offers new versions itself (right-click the mic → Check for Updates…).

Requires macOS 26 on Apple silicon.
